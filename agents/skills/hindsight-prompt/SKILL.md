# Hindsight prompt

Create one paste-ready prompt for a fresh session.

**Hindsight** carries forward what was expensive to learn.
**Clean-room** assumes zero session history.

Read the conversation as an evolving specification.
Infer its current:

- End goal
- Value order
- Success test
- Evidence standard
- Bounds
- Sources
- Open tensions.

Give later corrections their intended effect on earlier context.

Write for the end state.
Carry forward discoveries, failed framings, and useful leads.
Keep fixed requirements distinct from provisional choices.
Leave the fresh agent room to test the framing and choose its approach.

Include links, paths, artifacts, and skill names that the new session needs.

Run a clean-room read:

- Can a capable agent act without prior context?
- Can it avoid the expensive dead ends?
- Can it improve on the current approach?
- Can it prove completion?

Restore missing context.
Cut anything that does not change direction, judgment, or evaluation.

Return only the paste-ready prompt.
