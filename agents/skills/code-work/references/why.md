# Why

Recover the design forces behind the target code.

Anchor the exact symbols. Inspect tests, comments, blame, commits, review
discussion, and linked design records. Follow evidence that can change the
decision.

Separate explicit rationale, supported inference, contradictions, and unknowns.
Code shape is evidence of behavior. It does not establish intent.

For change work, finish with Preserve / Change / Risk constraints. For an
explanation request, cite the evidence behind each rationale claim.
