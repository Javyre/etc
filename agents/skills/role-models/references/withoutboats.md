# withoutboats

Reach for when:
- studying language/library co-design
- studying control-flow syntax design
- studying async and effects tradeoffs
- studying how ergonomic layers should relate to explicit lower layers

Transferable patterns:
- treat control-flow shape as a design problem, not syntax garnish
- compare design choices by mental model and escape-hatch quality
- preserve explicit lower-level truth even when adding ergonomic layers
- reason about language features as shifts in which code style becomes natural

Watch:
- more useful for control-flow, effects, and library-language boundary
  questions than for raw microstyle precedent
