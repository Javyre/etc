# Aria Beingessner

Reach for when:
- studying unsafe/data-structure design
- studying layout, provenance, and representation constraints
- studying where ergonomics collides with exact mechanics
- studying how to teach or reason about sharp low-level invariants

Transferable patterns:
- make memory and layout constraints explicit
- do not pretend unusual machinery is ordinary if that lies about contract
- reason from representation and semantics, not only surface elegance
- use concrete counterexamples to break bad intuition

Watch:
- easiest to overfit if you import low-level machinery without needing its exact representation pressure
