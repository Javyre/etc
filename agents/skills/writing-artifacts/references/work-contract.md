# Work contract

Primary audience: the implementation owner. Secondary audience: the approver.

Purpose: define work precisely enough to build, review, and accept.

Include:

- intended outcome and observable behavior
- contract and scope boundaries
- constraints and non-goals that change implementation choices
- proof bar and acceptance conditions
- unresolved decisions that block correct execution

Include current implementation detail only when it changes the outcome,
contract, constraints, or proof bar.

Complete when the implementer can act without reconstructing intent and the
approver can distinguish acceptance from rejection.
