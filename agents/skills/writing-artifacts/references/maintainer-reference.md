# Maintainer reference

Primary audience: the maintainer locating truth or changing the system.

Purpose: expose stable ownership, contracts, lifecycle, and proof paths.

Include:

- authoritative source locations and owners
- public contracts and important invariants
- state, lifecycle, and failure behavior
- safe change and verification paths
- sharp edges that code or configuration does not reveal cheaply

Point to discoverable source and configuration. Explain the facts and reasons
that a direct lookup cannot recover.

Complete when the maintainer can locate the controlling truth and make a safe
change without reconstructing the system from scratch.
