# User or operator guide

Primary audience: the person performing the named task.

Purpose: make the task executable and recoverable.

Include:

- named prerequisites and starting state
- ordered actions in the user's vocabulary
- observable success state
- expected failures and recovery actions
- links to reference detail needed during execution

Expose implementation detail only when the reader must reason about it to act
safely.

Complete when the reader can perform the task and recover from expected failure
using the document alone.
