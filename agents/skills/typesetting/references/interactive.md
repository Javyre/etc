# Interactive pages

For a page whose interaction the user approved. The stance is direct
manipulation: the reader acts on the model's own representation and sees
the consequence at once, where they are looking.

- **The representation is the control.** Drag the order, the point, the
  bar. Fields and forms make the reader translate intent into syntax; keep
  exact entry as a secondary path.
- **Immediate, local, reversible.** Feedback lands in the frame being
  watched; nothing else moves, in any state. Every action undoes, and the
  whole state round-trips as a pasteable string the user can hand back as a
  default.
- **A question for each control.** A model to play with and no question is
  a toy. Pose the reader's questions as scenarios to try, ordered from the
  core model to its exceptions; each control answers one.
- **Comparison within the eyespan.** Rivals sit side by side, not behind a
  switch that taxes memory. To learn a taste, offer distinct directions to
  triangulate, not parametric neighbours.
- **The agent cannot see the page move.** An interaction works once it is
  observed in a browser: each state, element positions across states,
  response while dragging. Until then, report it as unobserved.
- **Controls follow the skill.** Quiet, in reach, in the kit's own visual
  language.

## Sources

- Ben Shneiderman, ["Direct Manipulation: A Step Beyond Programming Languages"](https://doi.org/10.1109/MC.1983.1654471): visible objects, physical actions, rapid reversible operations with immediate effect.
- Bret Victor, ["Explorable Explanations"](https://worrydream.com/ExplorableExplanations/): reading as active exploration of a model.
- Edward Tufte, [*Envisioning Information*](https://www.edwardtufte.com/book/envisioning-information/): small multiples, comparisons within the eyespan.
